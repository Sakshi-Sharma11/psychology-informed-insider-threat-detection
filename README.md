# psychology-informed-insider-threat-detection
Capstone thesis prototypes for psychology-informed anomaly detection using the CERT Insider Threat Dataset.

This repository contains the progression of prototypes developed for my
Capstone Thesis in MSc Computer Science: Adaptive Cybersecurity at the
University of Galway.

## Research objective

The project investigates whether behavioural anomaly detection can be
interpreted using psychology-informed behavioural categories to support
insider-threat detection.

## Dataset

The prototypes use the CMU CERT Insider Threat Dataset. The dataset is not
included in this repository. Users must obtain it from its official source
and comply with its applicable terms.
